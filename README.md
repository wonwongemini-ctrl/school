## 공통 안내
- 두 프로그램 모두 **인터넷으로 아무것도 보내지 않고** 브라우저 안에서만 동작합니다. 입력한 내용은 이 PC 브라우저에만 저장됩니다.
- 같은 브라우저에서 두 프로그램을 함께 써도 입력값이 섞이지 않습니다.
- 두 프로그램의 일정은 같은 사이트의 [교무실 업무 도우미](https://wonwongemini-ctrl.github.io/school/) 첫 화면 통합 달력·오늘 할 일에도 나타납니다(같은 브라우저 안에서만). 구성 도우미는 일정 메뉴, 운영 도우미는 이달 일정 달력 아래에서 끌 수 있습니다.
- 업무망 PC처럼 인터넷이 없는 곳에서는 프로그램 화면을 Ctrl+S로 저장해 HTML 파일로 열면 됩니다.
- 경기도 조례·지침 기준으로 만든 **참고용 도구**입니다. 최종 확인과 책임은 학교에 있습니다.

## 학운위 구성 도우미
학교운영위원회 구성(구성계획 → 선출 홍보 → 선출관리위원회 → 선출공고 → 후보 등록 → 결격사유 조회 → 명부·선거공보 → 투·개표/무투표 당선 → 지역위원 → 위원장 → 구성결과 홍보)의 기안문 31종(ODT)과 업무편람 별지 서식(HWPX)을 일정만 넣으면 한 번에 만듭니다. 법정 기한 점검, 무투표 자동 판정, 선거인 명부 엑셀 불러오기, 구성 완료 점검(실태점검·감사 항목), FAQ 검색을 지원합니다.
- 예시 자료: `hakwoonwi/sample_voter_roll_dummy.xlsx`(가상 인물 100명, 가짜 연락처)

## 학운위 운영업무 도우미
회의 개최·진행·결과 업무의 공문·공고·안내, 명패·안건 인덱스·봉투 라벨, 공개 시점·기한 점검을 돕습니다. 자세한 사용법은 [사용설명서(노션)](https://volcano-saturday-a54.notion.site/v2-0-3f99700e048c81f8968edd67b99a79fc)를 보세요.
