# 학운위 구성 도우미 (경기 공립 초등 기준)

매해 반복되는 학교운영위원회 **구성 업무**(구성계획 → 선출 홍보 → 선출관리위원회 → 선출공고 → 후보 등록 → 결격사유 조회 → 명부·선거공보 → 투·개표/무투표 당선 → 지역위원 선출 → 위원장 선출 → 구성결과 홍보)의 기안문과 별지 서식을 일정만 넣으면 한 번에 만들어 주는 프로그램입니다.

- **바로 쓰기(웹):** https://wonwongemini-ctrl.github.io/school/hakwoonwi/
- **내려받아 쓰기(업무망 PC 등 인터넷 없는 PC):** [`hakwoonwi/index.html`](hakwoonwi/index.html) 파일을 받아 크롬·엣지·웨일로 열면 됩니다.
- **지난 버전:** `hakwoonwi/v/버전.html` (예: [`v/2.6.5.html`](hakwoonwi/v/2.6.5.html))

## 무엇을 해 주나요
- 학교 K-에듀파인 기안 서식(.odt)을 불러와 **기안문 31종(ODT)** 을 우리 학교 서식 그대로 생성
- 업무편람 **별지 서식(HWPX)** — 위촉장·투표용지·당선통지서·선거인 명부·동의서 등을 원본 크기대로 생성
- 일정 입력 → 모든 문서·소업무 일정 자동 반영, **법정 기한 점검**(3.21·3.30·4.15, 주말이면 앞 평일)
- 후보 수로 **투표 / 무투표 당선 자동 판정**(학부모·교원·지역위원)
- 선거인 명부 **엑셀 불러오기**(학급별·학년별, 가구당 1표)
- **구성 완료 점검**: 실태점검표·종합감사 항목을 법령 근거와 함께 판정, 결과 HWPX
- 구성 관련 **FAQ 39건 검색**, 홈페이지 게시 대상 문서 표시

## 개인정보
- 프로그램은 **인터넷에 접속하지 않고** 브라우저 안에서만 동작합니다. 입력한 내용은 이 PC 브라우저에만 저장되며 어디로도 전송되지 않습니다.
- 공용 PC에서는 사용 후 **선거인 명부 비우기**를 해 주세요.
